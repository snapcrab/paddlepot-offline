# Contributing to PaddlePot Offline

Try the Mixer on your phone, share a session idea, report a bug you can reproduce, suggest a correction to the guide or send a small pull request.

- Use [GitHub Issues](https://github.com/snapcrab/paddlepot-offline/issues) for bugs, ideas and guide corrections. Open an issue before starting a substantial change.
- For a bug report, include the Mixer version (in **Settings**), your device and browser, the steps to reproduce it, what happened and what you expected. Use made-up player names in examples, screenshots and JSON attachments.
- Use [GitHub Pull Requests](https://github.com/snapcrab/paddlepot-offline/pulls) for proposed changes. Say what you changed and how you tested it.

Code you submit for inclusion is offered under the [MIT licence](./LICENSE), including for use in commercial products. Only submit material you have the right to license. If a change includes someone else’s material, identify the source and licence.

I review contributions in my spare time. For general feedback, email [hello@paddlepot.app](mailto:hello@paddlepot.app).
