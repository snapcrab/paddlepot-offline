# PaddlePot Offline

A doubles pickleball Mixer you can run in your browser.

- [Open the Mixer](https://snapcrab.github.io/paddlepot-offline/paddlepot-offline.html)
- [Download the HTML](https://github.com/snapcrab/paddlepot-offline/releases/latest/download/paddlepot-offline.html)
- [Download the ZIP](https://github.com/snapcrab/paddlepot-offline/releases/latest/download/paddlepot-offline.zip)
- [Read the user guide (PDF)](./paddlepot-offline-user-guide.pdf)

## v1.3.0

Turn on **Winner and loser racks** in **Settings** to split the waiting queue on **Play**. The latest saved result sends players to the **Winner rack** or **Loser rack**. Players with a draw or no result use the **Open rack**.

**Remix courts** takes four players from a single rack when possible, with the longest wait first within each rack. When no rack has four players, the mixer fills open courts from the combined waiting queue. The option is off by default and is included in local saves and JSON backups.

## v1.4.0

During a session, select **Courts → Add court** to open the next numbered doubles court, up to 24 courts. The new court appears on **Play** and can be assigned by **Remix courts** when your remix timing allows it and four players are available. Added courts are included in local saves and JSON backups.

## v1.4.1

Saved scores on **Play** use green for the winner, red for the loser, and a muted colour for draws. **Modify score** updates the colours when you save a correction.
