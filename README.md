# PaddlePot Offline

Run a doubles pickleball session in your browser.

| App | Play | Help |
| --- | --- | --- |
| Mixer v1.4.5 | [Open Mixer](https://snapcrab.github.io/paddlepot-offline/paddlepot-offline.html) | [Mixer User Guide](https://snapcrab.github.io/paddlepot-offline/paddlepot-offline-user-guide.html) |
| King of the Court v0.2.1 | [Open King of the Court](https://snapcrab.github.io/paddlepot-offline/paddlepot-kotc-offline.html) | [King of the Court User Guide](https://snapcrab.github.io/paddlepot-offline/paddlepot-kotc-offline-user-guide.html) |

**Use offline.** Open the app, save the page as an HTML file, then open that file in your browser. Try starting a session in airplane mode before heading to court.

**Move a session.** In the original copy, choose **Settings → Back up JSON**. Open the same app on the other device and choose **Restore JSON**. Restoring replaces the open session.
